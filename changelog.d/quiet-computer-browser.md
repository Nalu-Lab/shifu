- `shifu browser open` 默认不再弹出窗口：专用 Chrome 无界面运行，登录状态照旧保存在同一份专用配置里；需要本人登录或旁观时加 `--show`（旧的 `--headless`、`--headed` 仍可用）。可见窗口启动、开新标签时若抢走前台，会马上把前台还给原来的应用（本人那段时间用过键盘鼠标就不还）。`shifu computer` 的前台操作（`--restore-window`、`--foreground-fallback`）和剪贴板粘贴只在本人已有 10 秒没碰键盘鼠标时执行，否则返回 `user_active`；结束后还原原应用、窗口和鼠标位置。`SHIFU_COMPUTER_FOREGROUND=never` 或 settings.json 的 `"computer_foreground": "never"` 完全禁止前台。新增 `scripts/verify-quiet.py`，在自建窗口和本机页面上统计前台切换、鼠标移动和剪贴板改动次数。（辅助程序需重新安装）
- `shifu browser open` no longer shows a window by default: the dedicated Chrome runs headless with the same persistent profile; add `--show` for a person to log in or watch (`--headless` and `--headed` still work). When a visible window grabs the foreground at launch or on a new tab, the foreground goes straight back to the previous app (unless the person used the keyboard or mouse meanwhile). `shifu computer` foreground actions (`--restore-window`, `--foreground-fallback`) and clipboard paste run only after the person has been idle for 10 seconds, otherwise they return `user_active`; afterwards the previous app, window and pointer position are restored. `SHIFU_COMPUTER_FOREGROUND=never` or `"computer_foreground": "never"` in settings.json forbids the foreground entirely. New `scripts/verify-quiet.py` counts app switches, pointer moves and clipboard writes against your own test window and a local page. (Reinstall the helper.)
