- 新建任务的 Agent 下拉、「+」菜单和引导里，装了就会出现 Aider、Goose、Amp、Cursor CLI（`cursor-agent`）、Factory Droid（`droid`）、GitHub Copilot CLI（`copilot`）、Crush；没装的不列进「未安装」。它们作为普通命令启动，侧栏只显示在运行，退出后「恢复」是重新运行同一条命令。也可以在 `~/.shifu/app/agents.json` 里加自己的 CLI（`id`、`command`、可选 `label`、`args`、`install_url`），写错的条目会被跳过并说明原因。新命令 `shifu agents [--json]` 列出每个 Agent 在哪里找到、是否登录、怎么回报状态、来自哪里。需要同时更新 App 和 `shifu` 命令行。
- The agent dropdown, the "+" menu and the first-run guide now offer Aider, Goose, Amp, Cursor CLI (`cursor-agent`), Factory Droid (`droid`), GitHub Copilot CLI (`copilot`) and Crush once they are installed; missing ones are not listed under 未安装. They start as plain commands: the sidebar only shows them running, and resuming runs the same command again. You can add your own CLI in `~/.shifu/app/agents.json` (`id`, `command`, optional `label`, `args`, `install_url`); bad entries are skipped with a reason. The new `shifu agents [--json]` lists where each agent was found, whether it is signed in, how it reports status and where it comes from. Needs both the app and the `shifu` CLI updated.
