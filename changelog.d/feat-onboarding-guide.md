- The first time the app opens (no tasks yet) it shows a one-screen guide: pick the default agent (the first one found; install links and a tmux hint when none is), the permission choice, send a test notification (which also makes macOS ask for permission), and pick the first project folder; the task is then created and its first conversation opens with the default agent. It can be skipped, and new tasks still start with that agent. The agent picked in the new-task popover is now remembered across restarts.
