- 全新安装第一次开对话前，会先问一次 Agent 的权限：默认选「按 Agent 自己的设置」（推荐），「免确认（全权）」要自己选，并写明风险。以后在新建任务窗口的「权限」里照旧能改。从旧版升级的不会被问，保持原来的设置（没改过的仍是免确认）；还没回答时，任何启动 Agent 的路径都不会默认全权。
- 新增「准备情况」清单：列出 tmux、找到的 Agent，以及能可靠判断时（Claude、Codex、Gemini CLI）是否已登录；缺什么就给出可复制的安装命令和说明链接。出现在引导第一步和空白页，缺东西时启动后自动弹出，也可以从 Shifu 菜单「准备情况…」打开。需要同时更新 App 和 `shifu` 命令行。
- A fresh install now asks once, before its first conversation, how agents may act: 按 Agent 自己的设置 (each agent's own settings, recommended) is preselected, and 免确认（全权） (no confirmation) is an explicit choice with a one-line risk note. It can still be changed under 权限 in the new-task popover. Upgrades are not asked and keep their setting (no confirmation unless changed); until a fresh install answers, nothing starts an agent with no-approval flags.
- New setup checklist (准备情况): tmux, the agent CLIs found and, where it can be told reliably (Claude, Codex, Gemini CLI), whether each is signed in. Anything missing comes with the command to copy and an instructions link. It shows in the guide's first step and on the empty page, opens at start while something is missing, and is in the Shifu menu. Needs both the app and the `shifu` CLI updated.
