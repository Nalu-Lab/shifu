- 新 Mac 上不用先装 tmux：Shifu.app 自带一份（只用 macOS 自带的库），没装 tmux 时就用它；已经在用自己 tmux 的人照旧，正在运行的服务不会换成另一个 tmux。第一屏和「准备情况」里缺 Agent 时有「安装」按钮：它的官方安装命令在 Shifu 的终端标签里运行，看得到进度，装好后引导自动回来、Agent 出现在列表里；需要 npm 的 Agent 在没有 Node.js 时先说明，Claude Code 用不需要 Node 的官方脚本排在前面。没登录的 Agent 有「登录」按钮。「准备情况」还多了浏览器、电脑操作和通知三行，每行一个按钮。`shifu browser` 第一次使用时自己装好运行时（也可 `shifu browser install`，需要 Node.js 20+），不再要求 Shifu 仓库；`shifu computer` 第一次使用时把 App 自带的辅助程序放进 `~/Applications`，再由本人授权。
- A new Mac no longer needs tmux first: Shifu.app carries its own (linked only against macOS's libraries) and uses it when no tmux is installed; people with their own tmux keep it, and a running server is never switched to a different tmux. When no agent is installed, the first screen and the Setup Checklist offer Install: the agent's official installer runs in a Shifu terminal tab where you see it work, and once it is done the guide comes back with the agent listed. npm-based agents say so first when Node.js is missing, with Claude Code's Node-free official installer listed first. Agents that are not signed in get Sign In. The Setup Checklist also gains browser use, Computer Use and notifications rows, one button each. `shifu browser` sets up its runtime on first use (or `shifu browser install`; needs Node.js 20+) without the Shifu repo, and `shifu computer` copies the helper Shifu.app carries into `~/Applications` on first use, then the person grants its permissions.
