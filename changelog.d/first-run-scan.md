- A fresh install can create its first task again. With no recent folders, the new-task form's Project dropdown held only "Choose Folder…", already selected, so the folder dialog never opened. It is now a button, Create opens the folder dialog when no folder is set, and the empty page has Add Project. The first-run guide is now one screen: it finds the agents on this Mac and the projects in the usual code folders (folder names and modification times only, never file contents; Desktop and Documents only on a tap, so macOS does not prompt out of the blue). Tick projects and press Start to get one task per project with the first conversation open. The permission choice is saved on Start only; Skip changes nothing. The guide, the new-task form and the empty page are in English on an English Mac.
