- 应用内更新：菜单 Shifu →「检查更新…」，打开后每天也悄悄查一次（settings.json 里 `"update_check": false` 可关）；有新版时右下角出现小卡片，写着版本和更新说明，点「更新并重启」就下载、核对 Shifu 更新密钥的签名、替换 Shifu.app 并重新打开，Agent 对话在 tmux 里不受影响。App 自带的 CLI 一起更新；装过电脑操作组件的，新版第一次打开时用 App 里同版本的组件替换它，权限保留。0.4.3 及更早的版本要最后手动下载一次。
- In-app updates: Shifu → Check for Updates…, plus a quiet check once a day after opening (`"update_check": false` in settings.json turns it off). When there is a new version, a small card shows its version and notes; Update and Restart downloads it, checks it against Shifu's update key, replaces Shifu.app and opens it again, while agent conversations keep running in tmux. The CLI inside the app updates with it, and an installed Computer Use helper is replaced by the app's copy of the same version on the first open, keeping its permissions. 0.4.3 and earlier need one last manual download.
