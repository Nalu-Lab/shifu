- Agent 启动后几秒内就退出时（没找到命令、没登录、Node.js 太旧），面板不再只写「已退出」：会说明原因，给出可以复制的安装或登录命令（如 `claude auth login`、`npm install -g @openai/codex`）、安装说明链接和最后几行输出；点「重试」按第一次的方式重新启动，不去接续别的对话。需要同时更新 App 和 `shifu` 命令行。
- When an agent ends within seconds of starting (command not found, not signed in, Node.js too old), its panel no longer just says "已退出". It explains why, shows the install or sign-in command to copy (such as `claude auth login` or `npm install -g @openai/codex`), the install page link and the last lines of output; "重试" starts it again the way it was first started, without picking up another conversation. Needs both the app and the `shifu` CLI updated.
