- 新建对话只列出这台 Mac 上真正装了的 Agent：Shifu 按你终端里的 PATH 找（用 nvm、volta、bun 等装的 CLI 也能找到），没装的列在「未安装」里，点名字打开安装说明；记住的 Agent 没装时，默认改用第一个装了的。空白页会说明找到了哪些 Agent，没有 tmux 时先提示安装。回到窗口会重新检查，刚装的 CLI 会直接出现。需要同时更新 App 和 `shifu` 命令行。
- New conversations list only the agents actually installed on this Mac. Shifu looks them up on your terminal's PATH, so CLIs installed through nvm, volta, bun and the like are found. Missing agents are listed under "未安装"; clicking one opens its install page. If the remembered agent is missing, the first installed one becomes the default. The empty screen says which agents were found and asks for tmux first if it is missing. Returning to the window checks again, so a newly installed CLI shows up. Needs both the app and the `shifu` CLI updated.
