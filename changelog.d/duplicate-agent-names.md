- 修复同一个对话同时出现在两个任务里的问题。对话的记录如果在 App 外被删掉（例如在会话里运行 `shifu act close`），原任务仍会留着它的名字，之后新开的对话可能沿用这个名字，于是同时属于两个任务。现在新名字会避开任务清单里还列着的名字；App 启动时会去掉已不存在的名字，同一个名字出现在多个任务里时只留在它所属的那个。只需更新 App 和 `shifu` 命令行。
- Fixed a conversation showing up in two tasks. If a conversation's record was deleted outside the app (for example by `shifu act close` run inside a session), its old task kept the name, and a later conversation could reuse that name and belong to both tasks. New names now skip any name a task still lists. At startup the app drops names whose conversation is gone, and a name listed in several tasks stays only in the task it belongs to. Needs the app and the `shifu` CLI updated.
