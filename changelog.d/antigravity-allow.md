- Antigravity 不再被一律放行：Shifu 写在全局 `~/.gemini/config/hooks.json` 里的工具 hook，以前对每次工具调用都回答「允许」，连 Shifu 之外运行的 Antigravity、以及选了「按 Agent 自己的设置」的对话也一样。现在只有 Shifu 以「免确认」启动的 Antigravity 才放行，其他情况照常由 Antigravity 自己询问。下次在 Shifu 里打开 Antigravity 时 hooks 文件会自动更新。
- Antigravity is no longer approved everywhere. The tool hook Shifu writes into the global `~/.gemini/config/hooks.json` used to answer "allow" to every tool call, including Antigravity run outside Shifu and conversations set to each agent's own settings. Now it approves only for an Antigravity that Shifu started in no-confirmation mode; everywhere else Antigravity asks as usual. The hooks file updates itself the next time Shifu opens Antigravity.
